# CAN_IO_GUI
Handles the PC side for displaying data, testing, and setting up CAN device registers.
This is linked to the CAN_IO device:
https://github.com/jtoobias/CAN_IO

The CAN ID and Baud rate need to be set correctly according to the CAN-IO board.
